# AcousticFlow — 配布検証デモ

**この音響エンジンの音を、他人の環境で、他人の音源で確かめるための最小プロジェクト。**

本体プロジェクトから **Assets を丸ごと複製**して、扉のシーン 1 本だけを残したものです。
形状・材質・設定はすべて本体と同じで、再構成はしていません。

## 使い方

`Assets/Scenes/Test_SwingDoor.unity` を開いて再生するだけです。

| キー | 動き |
|---|---|
| **5 / 6** | 扉を**開く / 閉じる**（押している間） |
| **Y** | **Unity 標準の作り方と聴き比べる**（下記） |
| WASD | 歩く |
| 右ドラッグ | 見回す |

**ヘッドホンで聴いてください。**両耳の差（時間差と音量差）で方向を出しているので、
スピーカーでは成立しません。

## いちばん聴いてほしいこと ── Y キーの聴き比べ

同じシーン・同じ音源で、**2 つの作り方**を切り替えられます。

### Unity 標準（`Y` を押した状態）

ゲーム業界でいちばん普通に使われている構成をそのまま実装してあります。

- リスナー→音源へレイを 8 本撃ち、通った割合を遮蔽度にする
- 遮蔽度からローパスの遮断周波数と音量を決める
- 空間化は Unity 内蔵のパンナー（`spatialBlend = 1`）
- 残響は `AudioReverbFilter`
- 急変を避けるため時定数で平滑

藁人形にしないよう、複数レイのソフト遮蔽も平滑化も入れてあります。

### AcousticFlow（既定）

- 回折を**前川の式**と**フレネル開口積分**で使い分け（角・衝立は前川、戸口は開口積分）
- HRTF は **MIT KEMAR の実測**（710 方向）
- 残響は**実測エコグラム**（リスナーから 512 本 × 24 バウンス）から毎回組み直し
- **ベイクしていません。**壁を動かせば次のフレームから音が追従します

### 違いが出るところ

扉をゆっくり開けながら `Y` で切り替えると分かります。

| | Unity 標準 | AcousticFlow |
|---|---|---|
| **音がどこから来るか** | **音源の方角**（扉が閉じていても） | **開口の方角**（回り込んで届くので） |
| **開き具合** | レイが通るか通らないかの二値 | 角度に応じて**連続**に変わる |
| **音色** | ローパス 1 段（こもる／こもらない） | **帯域ごと**に開く（狭い隙間は高い音だけ通る） |
| **遮蔽の境目** | レイを跨いだ瞬間に段差 | 影境界で連続に引き継ぐ |

★「狭い隙間は高い音だけ通る」はイコライザで作った演出ではありません。
フレネルゾーンの半径 `r = √(λd₁d₂/(d₁+d₂))` が波長に依存することから自動的に出ます。
現実の扉の開閉を収録した実測（開−閉の差が 125Hz +2.6dB / 1kHz +10.3dB）と傾向が一致します。

## 音源を差し替える

シーンの音源には WAV が割り当ててあります。差し替えるなら、`Source_Right` /
`Source_Left` の `AudioSource` の Clip を入れ替えてください。

## 構成

```
Assets/
  Scenes/Test_SwingDoor.unity      本体からの複製（無改変）
  Scripts/AcousticFlow/            エンジンの C# 側 11 本
  Scripts/StockUnityCompare.cs     Y キーの聴き比べ（このデモ専用）
  Plugins/x86_64/AcousticEngine.dll  エンジン本体
  StreamingAssets/kemar.afhr       HRTF（MIT KEMAR）
  Audio/                           音源
```

本体には比較用の C# 実装（`IrConvolver`）もありますが、**このデモでは外して
C++ 経路に固定**しています。経路が 2 つあると何を聴いているのか分からなくなるので。

## うまく鳴らないとき

| 症状 | 見るところ |
|---|---|
| 何も聞こえない | `AudioSource` に Clip が入っているか |
| 定位しない | ヘッドホンか。スピーカーでは成立しません |
| `Scene 生成失敗` | `Assets/Plugins/x86_64/AcousticEngine.dll` があるか |
| 響かない | `StreamingAssets/kemar.afhr` があるか |

Console に `[AcousticFlowScene] DSP 経路: C++ (VoiceConvolver) 2 個` と出ていれば正常です。
