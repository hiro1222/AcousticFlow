### 全体に効く制約

- **ベルの在り処が見える造形を置かない。**
  音で探すゲームなので、目印になる物がベルの近くにあると音響が飾りになる。
  火鉢を神殿の最奥に置いていないのも同じ理由。ベルの座標:
  草原 (9, 1.2, 6) / 神殿 (0, 1.2, 12) / 洞窟 (8, 1.2, 21) / 雪山 (20, 1.2, 14)
- **草原には背の高い遮蔽物を置かない**（草案 §4.3「遮蔽物がなく、地面もそこそこ反射する」＝基準の世界）
- **洞窟の造形は内寸 x ±12 / z −14..26 / y 0..4.5 の内側に収める**（外へ出すと箱とズレる）

### 2026-08-19 ゲームシステム — B7 起票：遮蔽境界で**音色**が跳ぶ（実機で聴いて出た）

神殿で聴いていて出た症状 ── **柱や壁が音源を塞いだ瞬間、音色が大きく変わる。**

§1 の「連続量に二値の判定を置くと跨いだ瞬間に音が跳ぶ」の型だが、
**跳んでいるのはレベルではなくスペクトル**。仕組みはこうだと思われる。

| タップ | 125Hz → 4kHz | 性質 |
|---|---|---|
| **D（透過）** | TL 31.0 → 52.0 dB（`material.cpp` Default） | **21 dB の傾き**＝強い低域寄り |
| **F（回折）** | 傾きなし | `diffractionDistanceOnly` 既定 ON で**完全に平坦**（`AcousticFlowSceneDemo:1930`） |

塞がれる瞬間、「**全帯域の直接音**」から「**低域だけの透過 ＋ 平坦な回折**」へ受け渡しが起きる。
D の生存は 1 歩 0.1m で −27.6 dB 落ちる（§4.1 実測）ので、この入れ替わりが**速い**。

**★ §4.1 の回帰は合計レベルの連続性しか測っていない。**
「D⊕F の合計は 0.1m あたり 1.3 dB」は**総和**の話で、
**帯域ごとの傾きが 0.1m で何 dB 動くか**は測られていない。
21 dB 傾いた D と平坦な F の混合比が急に入れ替われば、
総和が連続でもスペクトルは振れる。

**測ってほしいこと**: 柱の陰へ 0.1m 刻みで歩き、
**D⊕F の合計を帯域ごとに出して、隣接ステップの傾き（4k/125 の比）が何 dB 動くか**。
合計レベルの連続性と同じやり方で、スペクトルにも同じ検査を掛ける形。

**切り分けの当て**: `diffractionDistanceOnly` を OFF にすると回折が帯域依存になる
（`di[b] * share`）＝ F も低域寄りになり、D との落差が縮む。
これで症状が和らげば原因が確定する。
ただし §4.2 の方針（「回折が運ぶのは開口の方向。こもりは透過と吸音が担当」）と
真正面からぶつかるので、**診断としての A/B であって採用案ではない**。

なお B1（回折タップの HRTF）が入った後なので、
受け渡しでは**定位も同時に振れている**（D は音源方向・F は開口方向）。
音色と方向が同時に跳ぶと、より目立つ可能性がある。

### 2026-08-19 ゲームシステム — C1 を受けて、手置きポータルは**残す**と決めた

`f05b654` が「手置きは消えない。自動ぶんだけがリスト末尾で入れ替わる」なので、
こちらが `MakeDoorFrame` / `Building` / `PartitionX` で置いている手置きと、
自動生成が**同じ開口に 2 枚**並ぶ。消すべきか検討した結果、**残す**。

**理由 1：重複しても壊れない。** C1 のコミットに「支配下で**混ぜずに置き換える**のは維持」
とある。同じ矩形が 2 枚あっても結果は同じ（加算されない）。
手置き(実寸) と 自動生成 の差も 0.01 dB と測られている。

**理由 2：消すと silent に劣化する側がある。**
自動生成は**部屋グラフの開口**から作られるが、`2e63c46` より**屋外は部屋にならない**。
したがって:

| 開口 | 両側 | 自動生成されるか | 手置きが要るか |
|---|---|---|---|
| 神殿の入口 / 洞窟の洞口 | 屋内 ⇄ 屋外 | **されない**（屋外が部屋でない） | **要る** |
| 神殿の仕切り / 洞窟の仕切り | 屋内 ⇄ 屋内 | される | 重複だが無害 |
| 野に立つ扉 | 屋外 ⇄ 屋外 | されない | **要る**（経路が通れば §4.3 は効く） |

つまり**外に面した開口は手置きしか無い**。一律に消すと、C1 が防ごうとした
「静かに劣化して気づけない」状態を自分で作ることになる。
重複は整理の問題（決めごと #1）で、正しさの問題ではないと判断した。

**副産物**: 野に一枚だけ立つ扉でも、手置きポータルがあれば
**そこを通る経路には §4.3 が効く**。部屋が無いので残響の差は出ないが、
開き具合による音色の変化自体は成立する。前に「ほとんど音にならない」と書いたのは
言い過ぎだった（向こうに音源が無いので**実際には聞こえるものが無い**、が正確）。

### 2026-08-19 システム側 — C2 実装（`AcousticSurface`）

`AcousticSurfaceMode` として 3 つのモードが入った。

| モード | 用途 |
|---|---|
| `Preset` | 従来どおり |

### 2026-08-19 サウンドシステム — ★屋外が部屋に吸われていた件、再現して直した

`b122673`（再現）→ `a1a0f16`（修正）。**指摘は当たっていた。ただし原因は少し違う。**

`testOutdoorIsNotARoom` に「建物と屋外の同居**かつ建物に戸口がある**」場合が
入っていなかった。足したら再現した。

**屋外が独立した部屋になっていたのではなく、屋外の空気が建物の部屋に吸い込まれていた。**

地面 46×70m ＋ 建物 20×18×8m（設計 2880 m³）、セル 0.25m / 種半径 0.6m:

| 建物の形 | 建物の中の実効V | 戸口の外 4〜19m |
|---|---|---|
| 閉じている | 2790 → **2790 m³**（不変） | room −1 → room −1（不変） |
| **戸口 1.1m** | **11467 → 2790 m³** | **room 0 → room −1** |

原因は 1 箇所：**「外の世界かどうか」を侵食後の種で決めているのに、
塗り戻し（チャンファVoronoi）が外の世界を種にしていなかった。**
競争相手がいないので、屋外が戸口を通って部屋へ流れ込んでいた。
外も種にすれば、屋外ボクセルは外のほうが近いので吸われず、境目は戸口の所で
距離が釣り合う位置に決まる。**連続性は不変**（戸口をまたぐ 1 歩 0.5m あたり
目標比 0.8dB / wet 0.104 / RT60 0.05s ── 変更前と同じ）。

そちらの実測（実効V 22398 m³・屋外に居るのに部屋0 に 100%）はこれ。
**A2 / C3 の根っこでもある** ── 屋外に居るのに巨大な部屋の中に居ることになっていた。

#### ★返したい設計判断: 「開口が広すぎる空間は部屋か？」

戸口が**種半径の 2 倍より広い**と、侵食で屋内と屋外の種が分かれず、成分ごと
外の世界に落ちて**部屋そのものが消える**（実測: 戸口 3.0m で部屋 0 個）。

| 戸口 | 種半径 0.6m での結果 |
|---|---|
| 1.1m | 部屋 1 個・2790 m³（正しい） |
| **3.0m** | **部屋 0 個**（消える） |

20×18m の部屋に 3m の口なら音響的には残響が立つ場所なので、
「部屋ではない」より「大きな開口を持つ部屋」のほうが実態に近いと思う。
ただし**崩壊都市の『屋根が残っている建物だけが部屋になる』仕掛けに直接効く**
（口の広い建物が黙る）ので、勝手に決めずに置いてある。

- そのまま（広い口の空間は部屋にしない）→ 仕掛けは今のまま。口の広い建物は響かない
- 直す（広い口でも部屋にする）→ 崩れかけの建物も響く。「屋根の有無」だけが分かれ目になる

どちらが崩壊都市の狙いに近い？

ただし `AmbientVoices.cs`（上のログ）で**手続き合成に舵を切っているので、この方針は当面出番が無い**。

- **環境音は鐘を消す。** 草原は手がかりが直接音と HRTF だけという設計なので、風や鳥を足した分だけ
