# 回折モデル：UTD ＋ エッジカタログ（Phase 4）

> **⚠ この文書は現行の音声経路を説明していない（2026-08-03 以降）。**
>
> UTD は影境界で不連続になるため音声経路から外し、**前川の式**に置き換えた
> （実測: 段差 12.5dB → 0.35dB）。現行の設計は **[DIFFRACTION_DESIGN.md](DIFFRACTION_DESIGN.md)**、
> 判断の経緯は **[DEV_LOG.md](DEV_LOG.md) G章** を参照。
>
> UTD 自体は `Core/utd.h` と `AF_SceneComputeDiffractionBandsUtd` として残っており、
> 回帰テストで採用版と並べて出力している（選択の根拠を数値で保守するため）。
> **この文書はその UTD 実装のリファレンスとして有効。**

音が障害物の縁を「回り込む」回折を、幾何音響で扱うための実装。使った理論と、実際に何を
書いたかをまとめる。関連コード：`AcousticEngine/src/Core/utd.h`（UTD本体）、`scene.h`
（エッジ探索と統合）。

---

## 1. 何を計算しているか

回折点 **P**（障害物のエッジ上の点）を音が通って音源 S からリスナー L へ届くときの、
**帯域別の相対ゲイン(0..1)** を出す。1.0＝自由音場と同じ、0＝完全遮断。

- 直接（見通し）が塞がれても、エッジを回り込む分が P 経由で届く。
- **低域ほど回り込みが強い**（長波長は縁を回れる）＝物理どおり。

---

## 2. 理論

### 2-1. 回折点 P はどこか（Fermat / Keller）
- **Fermat の原理**：P は「S→P→L の経路長が停留（最短）になるエッジ上の点」。
- **Keller の回折の法則(GTD)**：回折波はエッジ周りの **Keller コーン**（入射角＝回折角）に
  沿って出る。S・L・エッジ方向が決まれば P は一意。

### 2-2. UTD（Uniform Theory of Diffraction）
Keller の GTD は影/反射の**境界で発散**する欠点がある。**Kouyoumjian & Pathak (1974)** は
**遷移関数 F(X)**（Fresnel積分ベース）を掛けて境界を**連続化**した。これが UTD（"Uniform"）。

回折係数（4つの余接項）：

```
D = -e^{-jπ/4} / (2n √(2πk) sinβ0) × Σ_{i=1..4} cot(β_i) · F(kL a_i)
```

- **n**：ウェッジ指数（外部角 = nπ）。半無限スクリーン=2、凸な箱の稜線（外部270°）=1.5。
- **β0**：入射線とエッジのなす角（Keller コーン半角）。
- **φ', φ**：0面から測った入射角・回折角。
- **s', s**：S→P、P→L の距離。**L = s's·sin²β0/(s'+s)**（距離パラメータ）。
- **k = 2πf/c**：波数。この **1/√k が「低域ほど回り込む」の中核**。
- **前2項**＝入射影境界(ISB, φ−φ')、**後2項**＝反射影境界(RSB, φ+φ')。

**遷移関数** `F(X) = 2j√X e^{jX} ∫_{√X}^∞ e^{-jτ²}dτ`：X→0（境界）で F→0、X→大で F→1
（＝素の GTD に戻る）。境界で cot が発散しても F→0 が相殺し、総和は有限＝連続。

**相対ゲイン（自由音場基準）** に落とすと簡潔になる（本実装で使用）：

```
gain_band = |Σ cot·F| / (2n √(2π k L))
```

影境界で ~0.5（−6dB、周波数によらず）、影の奥ほど減衰、低域ほど残る。

### 2-3. なぜ Maekawa でなく UTD か
- Maekawa は単一の経験カーブ（フレネル数 N=2δ/λ の関数）で、**境界の不連続**・**ウェッジ角**・
  **反射境界**を扱えない。プレイヤーが縁をまたぐとき「がくっ」と変わる。
- UTD は **境界で連続**（遷移関数）・**任意ウェッジ角**・**反射境界も込み**・複素（位相も持つ）。

### 2-4. エッジカタログ（キューブマップ）— B
どのエッジで回折するかを見つける手段。**リスナー中心にキューブマップ状(6面×res²)にレイを
撒き、隣接セルの深度が不連続に飛ぶ所＝シルエット稜線**として拾う（＝画像のエッジ検出）。
1回のレイ撒きを全音源で共有できる（リスナー係留＝音源数非依存）。実装済み（§3-3）。

## 3. 実装したもの

### 3-1. UTD 本体：`Core/utd.h`
- `fresnelCS(x, C, S)`：Fresnel積分 C(x)/S(x) の有理近似（Abramowitz & Stegun 7.3.32-33、
  誤差<2e-3）。
- `transitionF(X) → complex`：遷移関数。Fresnel積分から
  `∫_{√X}^∞ e^{-jτ²}dτ = √(π/8)(1-j) − √(π/2)[C(w)−jS(w)]`（w=√(2X/π)）を作り、
  `2j√X e^{jX}` を掛ける。X→大で 1、X→0 で 0 を数値確認済み。
- `cotTimesF(...)`：cot((π±β)/2n)·F を計算。**影/反射境界で cot が特異になる所は
  Kouyoumjian-Pathak の極限 `n√(2πkL)·sgn·e^{jπ/4}`（→ |term|/(2n√)=0.5）に切替**。
- `utdGain(n, β0, φ', φ, s', s, out6)`：角度直接版。4項の複素和を取り、
  `|Σ| / (2n√(2πkL))` を6帯域で。
- `utdWedgeGain(source, P, listener, edgeDir, refTangent, n, out6)`：位置＋幾何版。
  エッジ⊥平面に基底を張り φ', φ, β0 を作って `utdGain` を呼ぶ。

**検証（`utd_test.cpp`、n=2 スクリーン, φ'=45°, s'=s=5m）**：
- 影境界 225° で全帯域 ~0.45（周波数非依存 ＝ 物理的に正しい）
- 影の奥へ単調減衰（230°→320° で低下）
- 低域 > 高域（125Hz > 1kHz > 4kHz）
- 全域で連続（がくっと飛ばない）

### 3-2. エッジ探索と統合：`Core/scene.h`
- `diffractionDetour(from, to, outPoint, outEdgeDir, outRefTangent)`：箱(OBB)の12稜線を
  数点サンプルし、両区間見通せる δ最小の点 P を探す。**最良稜線のエッジ方向・0面接線
  （UTDのウェッジ幾何）も返す**。箱は凸稜線なので n=1.5。
  ※ これは B（キューブマップ エッジカタログ）の暫定版。
- `computeDiffraction` / `computeDirectSoft`：Maekawa→ITU→**UTD** と置換し、
  `utd::utdWedgeGain(source, P, listener, edgeDir, refT, 1.5, out)` を呼ぶ。

**箱シーン検証**：δ=0.275（影境界近く）で 125Hz=0.475 > 4kHz=0.123 ＝ 妥当。

### 3-3. エッジカタログ：`Core/scene.h`（B）
- `buildEdgeCatalog(listener, res, maxDist)`：リスナー中心に 6面×res² のレイを
  `cubeTexelDir` 方向へ撒き、各テクセルの深度・ヒットインスタンスを取る。**隣接テクセルで
  深度が相対15%以上飛ぶ／ヒット↔ミスの境界**＝シルエットとして、近い側のヒット点を
  `addCatalogEdge` で**最寄りの箱稜線に snap**（0面接線・n=1.5込み）してカタログへ。近接重複は除外。
- `diffractionDetour`：カタログがあればその稜線上を数点サンプルして δ最小P を探す。
  **有効な迂回が無ければ箱コーナー探索へフォールバック**（凸箱を正面から見る等の退化ケース対策）。
- デモは `BuildEdgeCatalog` を低レート（catalogUpdateEveryFrames）で呼び、全音源で共有。

**検証（`catalog_test.cpp`）**：
- 箱1個をリスナーから見て**シルエット4稜線を検出**。
- **薄い衝立**では、カタログ稜線で回折が成立（箱コーナーと同じ最適エッジ＝δ一致）。
- 凸箱が正面ちょうどのケースは前面稜線が裏で再遮蔽 → 箱コーナーにフォールバック（堅牢）。

## 4. 限界と今後

- **カタログの稜線抽出は箱前提**（`addCatalogEdge` が箱稜線に snap）。メッシュ対応は
  深度不連続の両側法線からウェッジを直に作る形へ拡張が要る。
- **凸箱を正面から見る退化ケース**は前面シルエット稜線が単一回折に使えず箱コーナーへ
  フォールバック（薄い衝立・実シーンではカタログが機能）。
- **単一回折のみ**（多重回折は将来）。
- **ウェッジ幾何の向き**：箱稜線から 0面接線を出しているが、反射境界(RSB)項の厳密さは
  向き設定に依存。主要な影回折（ISB項）は検証済みで妥当。
- **空間索引なし**：現状カタログは線形走査（稜線数は少ないので可）。多稜線シーンでは
  リスナー方向セクタの索引が要る（設計項1）。
- **再生方式**：本モデルの6帯域ゲインは、最終的に**フルIR畳み込み**（各レイに帯域＋方向＋
  到達時間を持たせ、HRTF両耳IRを合成→畳み込み）で鳴らす方針（設計決定）。現状はWwiseの
  Obstruction/Occlusion＋RoomVerbで近似駆動。
