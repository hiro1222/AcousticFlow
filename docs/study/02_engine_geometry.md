# 02 エンジン①：形・材質・部屋・戸口

エンジンが最初に知る物は「箱」と「材質」だけです。部屋も戸口も響きの長さ（RT60）も、そこから自動で出します。
人が部屋やポータルを置く必要はありません（Wwise の Rooms & Portals との違いはここ）。

読む順: `vec3.h` → `aabb.h` → `material.h/.cpp` → `world_rules.h` → `surfaces.h` → `surface_bvh.h` → `trace_scene.h` → `room_graph.h` → `probe.h`

---

## 1. 箱と材質

### `Core/vec3.h`・`Core/aabb.h` ── 箱（OBB）

- 世界の形は全部「回ってもよい箱」（OBB：中心・3 本の軸・半幅）です。三角形メッシュは使いません。
- `rayIntersectsObb`（スラブ法）がレイと箱の当たりを出します。箱のローカル軸へ写してから、軸ごとに出入りの t を取ります。
- `segmentIntersectsObb` は線分が箱を横切るか（見通しと回折の候補探しで使う）。
- 座標は Unity と同じ左手系（+x 右・+y 上・+z 前、単位 m）。Unreal はコネクタ層で並べ替えます（08 章）。

### `Core/material.h`・`Core/material.cpp` ── 材質

```cpp
struct AcousticMaterial {
    float transmission[kNumBands];   // 透過率（エネルギー比）。透過損失 TL[dB] = −10·log10(τ)
    float absorption[kNumBands];     // 吸音率（エネルギー比）
    float scattering[kNumBands];     // 散乱率（0 鏡面 … 1 拡散）
};
```

- **単位はエネルギー比**。振幅にするときは √ を取る。ここが混ざると壁越しの音が二乗ぶん小さくなる（実際に起きた）。
- プリセット（`defaultWall` `concrete` `glass` `woodDoor` `opaque` `woodRoom` `stone` `cave` `snow`）の値は **`material.cpp` だけ** にあります。
  Unity も Unreal も番号で引くだけで、表を持ちません（以前 C# 側にも表を持っていて 6〜8 dB ずれた）。
- 例：木の扉の TL は 125 Hz から 4 kHz で 15 / 19 / 24 / 29 / 33 / 36 dB（高いほど通しにくい ＝ 扉の向こうはこもる）。

### `Flow/world_rules.h` ── 世界の決まり

- 帯域の表 `kBandHz`（125…4k）と境目 `kCrossHz`（隣どうしの相乗平均）。**帯域の表はここだけ**。
- 音速 `kSpeedOfSound = 343`。
- 材質の表 `MaterialTable`（番号で引く。0 番は既定の壁）。
- `splitAt(材質, 帯域)`：面に当たったエネルギーを 反射 `1−α−τ`・透過 `τ`・吸収 `α` に分ける（和は 1。τ は 1−α で頭打ち）。
- `WorldWeights`：五成分の重み `w[5]`、隣の部屋の響きの重み `lateAdjacent`、影のこもり `shadowMuffleDb`。
  **掛けるのは配分の出口 1 か所だけ**（04 章）。帳簿（物理の量）には掛けません。

```cpp
// 影のこもり（2026-10-06）: 帯域 b で −S·b/5 dB（125 Hz は 0、4 kHz で −S）
void shadowMuffle6(float g6[kNumBands]) const {
    const float s = std::fmin(24.0f, std::fmax(0.0f, shadowMuffleDb));
    for (int b = 0; b < kNumBands; ++b)
        g6[b] = (s > 0.0f) ? std::pow(10.0f, -0.1f * s * b / float(kNumBands - 1)) : 1.0f;
}
```

## 2. レイが見る場面

### `Flow/surfaces.h` ── 箱の一覧

- 箱 ＋ 材質の番号 ＋ 「動く」印（`dynamic`、扉の板）＋ 有効の印。
- 2 つの問いに答えます：
  - `nearest`：レイが最初に当たる箱（t・当たり点・法線）
  - `transmittance`：線分 p0→p1 が横切る箱ごとに τ を掛けた積（壁越しの量）と、横切った枚数
- ★影のレイの始点を当たり点ちょうどにすると、自分の面に当たって全部遮られる。法線の側へ 1 mm 押し、自分の箱を除ける（`skip`）。

### `Flow/surface_bvh.h` ── 当たり判定の木

- 葉には箱の番号だけを入れます（ポインタも再帰も無い配列）。**GPU へそのまま持っていける形**にするためです。
- 動く箱があるので **毎フレーム作り直し**ます（数十個なら数 µs）。枝刈りは AABB、当たりは OBB。

### `Flow/trace_scene.h` ── 平らな配列

- レイトレースに要る物だけ（箱・材質ごとに前もって割った 反射/透過/吸収・木・部屋の格子）を配列にまとめた物。
- CPU のレイも GPU のレイも **同じこの配列** を見ます。答えが違ったときに「GPU だから」なのか「入力が違うから」なのかを切り分けるためです。
- `World::update` が 1 フレームに 1 回だけ組みます。

## 3. 部屋グラフ `Core/room_graph.h`（★この章の中心）

### 何をするか

置かれた箱から「部屋」と「戸口（開口）」を見つけ、部屋ごとに体積・表面積・平均吸音率・RT60 を出します。

```
 1) 動かない箱をボクセル（既定 0.25 m）に塗る：詰まっている／空いている
 2) 空いているボクセルごとに「壁からの距離」を測る
 3) 距離が侵食半径（既定 0.6 m）以上のボクセル ＝ 種。種の連結成分 ＝ 部屋
 4) 種でないボクセルを、最寄りの部屋へ塗り戻す（戸口の中にも部屋が付く）
 5) 別の部屋どうしが面で接している所 ＝ 開口（戸口）
 6) 部屋ごとに境界の面積と吸音率を集め、Sabine で RT60 を出す
```

**なぜ侵食するのか**：ただの連結成分だと、戸口で繋がった空間は全部 1 つの部屋になります。壁から半径ぶん内側だけを残してから繋がりを見ると、
幅が「半径 × 2」に満たない**くびれ**が先に千切れるので、部屋が戸口で分かれます（幅 1.2 m 未満の口で分かれる）。
洞窟の口のように広い口（3.5 m）で分けたいときは半径を大きくします（`AF_WorldSetRoomSeedRadius`、洞窟の地図では 2.1）。

**なぜ RT60 を形から出すのか**：レイの集計（エコグラム）から測ると、窓の長さに縛られて部屋の違いが出ませんでした
（吸音率が 17.6 倍違う 2 部屋で 0.50 と 0.51 秒）。Sabine なら形と材質だけで決まり、同じ 2 部屋が 4.34 秒と 0.25 秒になります。

```
RT60_b = 0.161 · V / (A_b + 4 m_b V)      A_b = Σ(面積 × 吸音率_b)、m_b は空気吸収
```

★**開口（戸口）は吸音率 1 として数えます**。戸口から出た音はこの部屋に戻らないので、音響的には「穴 ＝ 完全吸音」です。
部屋どうしの繋がりが、別の仕組みを足さなくても「戸口の面積」として自然に効きます。

### 結果の形

```cpp
struct Room {                 // 部屋
    int   voxels;             // 体積（ボクセル数）
    float surface, openArea;  // 境界の面積（開口を含む）と、そのうち開口の分
    float absorb[6], rt60[6]; // 平均吸音率、残響時間（帯域ごと）
};
struct Aperture {             // 戸口
    int   roomA, roomB;       // 繋いでいる部屋（外の世界なら roomA = −1）
    float area;               // 断面積
    Vec3  center, normal;     // 断面の重心と向き（A→B が正）
    Vec3  axisU, axisV;  float halfU, halfV;  Vec3 rectCenter;   // 外接矩形（扉の覆いを出すのに使う）
};
```

### 大事な決まり

- **動く箱（扉の板）は部屋グラフに入れない**。入れると、閉じた扉で戸口が消えて部屋が割れたまま開かなくなる。
  扉の開き具合は、毎フレーム別に出します（下の `probe.h` と 03 章の `aperture.h`）。
- 部屋グラフを組み直すのは、動かない箱が変わったときだけ（`dirty_`）。組み直したら FDN の器も作り直す（`AF_WorldFdnStale`）。
- 外の世界（格子の端に届く空間）は普通は部屋になりません。洞窟の口のように「外へ開いた部屋」を扱うときは `setOutsideMouth` で
  外への口を開口に含め、Sabine の吸音にも口を α = 1 で入れます。

## 4. 部屋の響きの数字 `Flow/probe.h`

- `probeFromRoom`：部屋グラフの `Room` から 体積 V（ボクセル数 × セル³）・表面積 S・平均自由行程 4V/S・RT60 を写す。
- `applyOpenings`：戸口に扉の板があるとき、その面積ぶんの吸音率を差し替えて RT60 を出し直す。

```
eff_b = a + (1 − a) · min(1, α_板,b + τ_板,b)      a = 板が覆っていない面積の割合（0 閉 … 1 全開）
```

全開なら 1（穴）、閉じれば板の吸音 ＋ 透過（透過した音もこの部屋には戻らないので吸音と同じ扱い）。
**「扉を閉めると部屋自身の響きが少し伸びる」** はこの式から出ます。同じ `a` が、配分（04 章）の戸口の量にも使われます（1 つの値で両方に効く）。

- `fdnLineScale`：FDN の遅延線の長さの尺度（平均自由行程 ÷ 音速 ÷ 12 ms）。

## 5. 下回り `Core/worker_pool.h`

- 音源ごとのループを複数コアへ割るための小さなプール。**既定はスレッド無し（直列）**。
- 音源ごとに自分の枠にしか書かないので、割っても答えはビット一致します。
- ★プールは世界が持ち、世界を壊すときに join します（DLL を外す途中で join するとエディタが固まる、定番の事故）。
