# 05 エンジン④：音を作る所（DSP）

ここから先は **振幅** で考える層で、オーディオスレッドで回ります。決まりは 1 つ：
**オーディオスレッドでは、メモリの確保・ロック・例外をしない**（途切れの原因になる）。確保は全部、作るとき（制御スレッド）に済ませます。

読む順（部品 → 組み立て）: `fft.h` → `partitioned_convolver.h` → `nonuniform_convolver.h` → `hrtf_set.h` → `hrtf_processor.h`
→ `early_reflect_conv.h` → `direction_bus.h` → `fdn_tail.h` → `fdn_room_mix.h` → `voice_renderer.h`

---

## 1. 全体の信号の流れ

```
 音源ごと（Voice = VoiceRenderer、音源の数だけ）                     耳の側（1 組だけ。全音源で共有）
 ┌──────────────────────────────────────────────────┐
 │ dry（モノラル）                                    │
 │  ├─ タップの列（EarlyReflectConv）                  │
 │  │    ├─ 直接（index 0）→ HRTF（HrtfProcessor）→ L/R ─┼─→ そのまま出力
 │  │    ├─ 回折 → 別の向きの HRTF → L/R ──────────────┼─→ そのまま出力
 │  │    ├─ 反射・透過 → 隣り合う 2 レーンへ（ITD は 1 本ずつ）┼─→ 方向バス DirectionBus ─┐
 │  │    └─ 拡散の分 → allpass で滲ませる → L/R ───────┼─→ そのまま出力          │ レーンごとに固定の HRIR
 │  └─ 響きの送り（尾の開始 ITDG だけ遅らせて）──────┼─→ 部屋ごとの FDN（FdnRoomMix） │
 └──────────────────────────────────────────────────┘     ├─ 自分の部屋 → レーンへ ─┘
                                                             └─ 隣の部屋 → 戸口の線音源（5 点の HRTF）→ L/R
```

**費用の考え方**：反射のタップは数十本になるので、1 本ずつ HRTF で両耳にすると重い（6 音源で半コア）。
タップを向きの近い 2 本のレーンへ振り分け、レーンごとに 1 回だけ畳む（費用がタップ数でなく向きの本数で決まる、音源の数にも依らない）。

## 2. 部品

### FFT と畳み込み

| ファイル | 中身 |
|---|---|
| `fft.h` | 反復 radix-2 の複素 FFT。回転因子とビット反転表は作るときに作る（実行時に確保しない）。逆変換は 1/N つき |
| `partitioned_convolver.h` | 一様分割 overlap-save。入力の FFT は 1 回、L/R で IR スペクトルだけ別。IR の差し替えは「遅延線は 1 本のまま、IR のスペクトルを 2 世代混ぜる」（器を 2 つ並べると新しい側の遅延線が空で −3.26 dB 痩せた） |
| `nonuniform_convolver.h` | 非一様分割（Gardner 1995）。小さいブロックから倍々に段を重ね、遅れを最小ブロック（64 サンプル ＝ 1.3 ms）だけにする |

### HRTF

| ファイル | 中身 |
|---|---|
| `hrtf_set.h` | 方向 → 左右の HRIR。実測ファイル（`.afhr`）の読み込みと、**合成の HRTF（球の頭）**。★読み込み時に各耳の立ち上がりを揃えて ITD を抜き、別に持つ。再生時に「ITD × 頭の大きさ」で掛け直す（頭囲 57 cm を既定） |
| `hrtf_processor.h` | 1 方向の両耳化：ITD（小数サンプルの遅れ）→ HRIR の畳み込み。向きが変わるときは新旧 2 本を 12 ms クロスフェード。700 Hz で分け、低域は HRIR を通さず ITD だけ |

合成の HRTF には前後・上下の手がかりがありません（実測を差したときだけ上・下に聞こえる）。

### タップの列 `early_reflect_conv.h`

- 入力を 6 帯域に割る（直列のクロスオーバー、境は隣どうしの相乗平均。全帯域を足すと元に戻る）。タップごとに 6 個の係数を掛けるだけで色が出る。
- 各タップを 鏡面 √(1−s)・拡散 √s に分ける（無相関なのでパワーで足し合う）。
- ★**タップの差し替えは、出力のクロスフェードでなくパラメータの補間**。遅れ・量・向きを補間するので、音像がスッと動くだけ。
  新旧 2 本を同時に鳴らすと、遅れの違う 2 本で一瞬ダブり櫛が立つ。
- 対応の無いタップは量 0 から立ち上がる／0 へ落ちる（虚像が生えた瞬間に本来の量で鳴り出す段差が、構造的に消える）。
- タップの対応は素性（`id`）で取る。

### 方向バス `direction_bus.h`

- レーン ＝ 向き × 2 耳。水平 8 本（45° おき）＋上・下 2 本（`verticalLanes = 2`）。リスナー座標で固定（頭が回るとタップの重みが隣へ移るだけ）。
- タップは隣り合う 2 レーンへ **等パワー** で振る（w0² + w1² = 1、境をまたいでも量が跳ばない）。
- ★**ITD はタップごと、ILD とスペクトルはレーンごと**。ITD までレーンの代表値にすると、同じレーンに集まった反射が同じ ITD を持って左右の相関が上がる（0.19 → 0.46）。
- 700 Hz より下は HRIR を通さない（実測の HRTF は測定の都合で低域が落ちているため。頭は波長より小さいので物理的にも素通しでよい）。
- 使い方：音源が `render` の中でレーンへ足し、耳の側が 1 ブロックに 1 回 `render` を呼んで左右へ足す。

## 3. 響き：FDN

### 帯域ごとの FDN `fdn_tail.h`

```
 入力 → 4 段の直列 allpass（拡散。粒っぽさ・金属感を消す）
      → 4 次のクロスオーバーで 6 帯域へ
      → 帯域 b ごとに独立した FDN：16 本の遅延線、各線に減衰 g_b,i、高速 Walsh–Hadamard（無損失の混合）
      → 6 本の和
```

- **減衰（Jot）**：線 i（長さ L_i）が 1 周するごとに g = 10^(−3·L_i / (fs·RT60_b))。線の長さに比例した減衰なので、全モードが同じ速さで減る。
  ★「高域が先に減る」を係数で作らない。RT60_b は部屋グラフの Sabine（材質＋空気吸収）から来る。
- **帯域ごとに輪を分ける理由**：1 本の輪の中で帯域ごとの減衰を掛けると、クロスオーバーの重なりで隣の帯域の遅い減衰が周回ごとに積み重なり、
  RT60 が最大 +62% 長く出た。帯域ごとに輪を分ければ漏れは入口の 1 回だけ。
- **量の校正**：解析式だけでは ±3〜6 dB ずれたので、作るときに 7 点の RT60 でインパルスを流して自分で測り、表で補正する。
- **連続性**：RT60 を変えても、目標の係数を置くだけ。遅延線の中身は触らないので、いま溜まっているエネルギーが次のサンプルから新しい速さで減る。
  ★遅延線の長さは実行時に変えない（変えると音程が動く）。

```cpp
// 帯域 b の FDN の 1 サンプル（fdn_tail.h の renderImpl、抜粋）
for (int i = 0; i < kLines; ++i) {
    const float y = base[lineOff_[i] + linePos_[b][i]];      // 線 i の出口
    bsum += y;
    f[i] = y * gainCur_[b][i];                               // 線ごとの減衰
}
for (int len = 1; len < kLines; len <<= 1)                   // 高速 Walsh–Hadamard（無損失の混合）
    for (int j = 0; j < kLines; j += len << 1)
        for (int k = j; k < j + len; ++k) { const float a = f[k], c = f[k + len]; f[k] = a + c; f[k + len] = a - c; }
const float xin = xb[b] * inGainCur_[b];                     // この帯域の入力
for (int i = 0; i < kLines; ++i) {
    base[lineOff_[i] + linePos_[b][i]] = xin * injW_[i] + f[i] * oNorm;   // 線の入口へ戻す
    if (++linePos_[b][i] >= lineLen_[i]) linePos_[b][i] = 0;
}
```

### 部屋ごとの配線 `fdn_room_mix.h`（★）

部屋ごとに `FdnTail` を 1 本持ち、**音源 → 部屋 → リスナー** と前向きにだけ配線します。

- **連成残響は配線から出る**：扉が開いていると、音源の音が戸口から隣の響く部屋へ入り、その遅い尾が戸口から戻る。閉めれば両方消えて自分の部屋の速さだけが残る。
- ★**FDN どうしを信号で結び返さない**：部屋の出力を相手の入口へ戻すと、開き具合 1 で発散した（共振器の山で往復の利得が 1 を超える）。
  物理の「拡散エネルギーの交換」は、位相の揃った信号の帰還ではない。部屋自身の RT60 が扉で変わる分は、パラメータ側（02 章の `applyOpenings`）で出す。
- **帯域の色**：帯域 b の入力を √(RT60_b / 平均) 倍（拡散音場の定常エネルギーは RT60 に比例する）。
- **向き（レーン）**：方向バスが差してあれば、L/R の 2 本でなく **レーンごとに Hadamard の別の行** を出す（行どうしは直交 ＝ 無相関なので、向きごとに別のノイズ）。
- **点と拡散を分ける**（`laneModel 1`、既定）：
  - 拡散の分（自分の部屋）… レーン × 耳ごとに別の行（左右が無相関）
  - 点の分（戸口越しの向き）… 1 本の波形を、耳ごとに点の向きの ITD（小数、8 点の Lanczos で読む）で遅らせ、隣り合う 2 レーンへ等パワーで振る
  - ★点まで耳ごとに別の行にすると、左右が無相関で ITD が効かず、向きが変わると波形が入れ替わる（正弦で 12 dB の段差）。
- **形**：`setListenerLaneShape` で、自分の部屋の響きを壁までの距離の形でレーンへ配る（04 章）。
- **戸口の線音源**（`setPortal`、最大 4 つ）：
  - 隣の部屋の FDN を、戸口の横幅の 5 点から HRTF で鳴らす。点ごとに FDN の別の行（同じ波形だと打ち消し合って真ん中に像が 1 つできるだけで、幅にならない）。
  - 3,000 Hz より下は 5 点を同じ波形にする（低域は相関が高いのが自然。両耳相関が距離によらず 0.6 前後）。
  - `directGain`：戸口から耳へ直接出す量、`feedGain`：耳の部屋の FDN へ流す量（流すのは一方向だけ。輪を作らない）。
  - 耳がその部屋に入ったら、戸口の線音源から自分の部屋のレーンへ 0.3 秒かけて受け渡す（`setPortalCrossfade`）。戸口をくぐる瞬間に響きの出どころが跳ばない。

## 4. 組み立て `voice_renderer.h`（★）

音源 1 本ぶんの信号の流れを束ねるだけで、部品は全部個別に検査済みです。ここが担うのは配線と、段ごとの計測です。
（下は `renderChunk` の要約。実物は 423〜665 行）

```cpp
void renderChunk(const float* input, int n, float* outL, float* outR, ...) {
    // ⓪ 行き先（FDN・方向バス）はチャンクの頭で 1 回だけ読む
    //    （2 回読むと、その間に制御スレッドが外した空ポインタを踏む。Unreal の Play 終了で実際に落ちた）
    FdnRoomMix* const fdn = fdnMix_.load(std::memory_order_acquire);
    DirectionBus* const bus = dirBus_.load(std::memory_order_acquire);

    // ① 響き：部屋の FDN へ「送るだけ」。尾の開始（ITDG）だけ遅らせ、量はチャンクの中で線形に寄せる
    if (fdn) { ... fdn->add(room, sendSrc, n, gStart, gEnd, dstOffset); }

    // ② HRTF はブロックの境で HRIR を取り込む
    // ③ サンプルごと
    for (int f = 0; f < n; ++f) {
        early_.processSample(dry, hrtfActive, l, r, scatSendL, scatSendR, directMono, difMono, laneOut + f, laneStride_);
        hrtf_.processSample(directMono, dirL, dirR);   l += dirL; r += dirR;   // 直接 → HRTF
        hrtfDif_.processSample(difMono, dfL, dfR);     l += dfL;  r += dfR;    // 回折 → 別の向きの HRTF
        l += diffL_.process(scatPrevL_, ...);  r += diffR_.process(scatPrevR_, ...);   // 拡散 → allpass
        l *= outputGain_; r *= outputGain_;
        outL[f] = l; outR[f] = r;
    }
    // ④ 反射のレーンを方向バスへ（outputGain をここで掛ける：バスは耳の側で足すので最後の掛け算を通らない）
    if (laneOut) bus->add(laneOut, n, laneStride_, outputGain_, dstOffset);
}
```

- ★**量は必ず時間方向に繋ぐ**：響きの量を 1 ブロックごとに段で変えると「ぷつぷつ」になった（段差が平常の 51.8 倍）。チャンクの中で線形に寄せる。
- ★**`outputGain` の掛け忘れ**：FDN と方向バスへ送る分は、耳の側で足されるので最後の `l *= outputGain_` を通らない。送る所で掛ける。
  検査が見逃したのは、等倍（1.0）で回していたから。検査は音源ごとに違う値にしてある。
- ★拡散の分は 1 サンプル遅らせてから滲ませる（allpass の最初のサンプルが鏡面の分と同じ瞬間に打ち消し合い、−1.2 dB 痩せていた）。

## 5. 旧の道（写すが、今は鳴らない）

`reverb_tail_ir.h`（レイの集計から尾の IR を組み立てる）と `tail_bus.h`（畳み込みの尾の共有バス）は、FDN に移る前の響きの作り方です。
