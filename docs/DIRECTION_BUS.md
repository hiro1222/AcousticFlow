# 方向バス ── 反射・回折のタップを N 方向 × 2 耳のレーンに束ねる（2026-09-04）

## 何を解くか
面の線で R タップが 48 本になり、タップごとの両耳化（耳ごとの遅延＋帯域別 ILD、0.13%/本）で音源あたり音声スレッドの 8%、6 音源で半コアになった。ゲームでは音響全体に 1 コアの 5〜10% しか渡せない。**費用が O(タップ) だと面の数で青天井**になるので、上限を作る。

## 形
- リスナー座標で固定した N 方向（水平の環、既定 8 = 45° 刻み）× 2 耳 の行を、リスナーに 1 組持つ（`DirectionBus`、dsp/direction_bus.h）。
- 音源のボイスは、方向のあるタップ（直接音と HRTF バス行き以外）を隣り合う 2 方向へ**等パワー**（w0²+w1²=1）で振って行へ足す。境をまたいでも音量が跳ばない。
- 行ごとに**固定の HRIR**（ITD を抜いて揃えた物、128 タップに切る）をモノラルで畳み、左の行は左耳へ、右の行は右耳へ。
- **ITD はタップごと**。タップ自身の耳ごとの遅延（HRTF セットの ITD）を「書き先の位置」で付ける（リングは 1 回しか読まない）。ILD とスペクトルは行の HRIR が担当。
- 方向は頭に対して固定なので、頭が回っても重みが隣へ移るだけ。HRIR のクロスフェードは要らない。
- 使い方は尾のバスと同じ: 音源が Render の中で送り、AudioListener のフィルタ（TailBusRenderer）が Render を 1 回呼んで足す。
- 固有遅延は分割の最小ブロック 128（2.7 ms）。タップはそのぶん早めて送る（`VoiceRenderer::setTaps`）。

## 退けた書き方（順に試して数字で捨てた）
| 案 | 結果 |
|---|---|
| 方向ごとにステレオ 1 本（ITD も方向の代表値） | 費用は最小だが、同じ方向に集まった反射が同じ ITD を持ち、環の IACC が 0.19 → 0.46（8 方向）／0.31（12 方向）。両耳相関の JND（0.05〜0.1）を超える |
| 方向 × 耳の行に、耳ごとにリングを読み直して送る | IACC は基準と合うが、1 音源 9% → 14%（読み直し 2 回＋16 行へ散る書き込み） |
| 分割の最小ブロック 64 | 小さな FFT が増えて 8 方向で 4.6%（128 なら 2.0%） |
| 12 方向 | 5.4%（8 方向 3.4%）。IACC の改善は 0.01 の桁で、聞き分けられない所に払う |

採ったのは「方向 × 耳の行 ＋ 書き先ずらしの ITD ＋ HRIR 128 タップ ＋ 最小ブロック 128」。

## 数字（DspRegressionTest `[方向バス]` と AfDspBench、2026-09-04、機械の負荷高め）
物差し（基準 = 1 本ずつその方向の HRIR で畳む。白色雑音 1 秒）:

| 配置 | IACC 基準 / 8 / 12 | ILD 基準 / 8 / 12 |
|---|---|---|
| 右半分の環 8 本（25° 刻み） | 0.193 / 0.180 / 0.172 | +6.9 / +7.0 / +7.5 dB |
| レーンの真ん中 1 本（22.5°） | 0.932 / 0.940 / 0.932 | +4.2 / +4.5 / +4.4 dB |
| 全周の環 14 本（25° 刻み） | 0.112 / 0.129 / 0.117 | +0.1 / +0.2 / +0.3 dB |

費用（48 kHz、ブロック 512、直接 + R48 + F7）:

| 条件 | 音源 1 本あたり | リスナー側の固定費 |
|---|---|---|
| タップごとの両耳化（従来） | 8.6%（6 本のとき 13.7%） | 尾のバス 4.0% |
| 方向バス 8 | 7.8%（6 本のとき 8.0%） | 尾 4.0% ＋ 方向 3.4% |
| 方向バス 12 | 8.0% | 尾 4.0% ＋ 方向 5.4% |

6 音源で 82% → 56%。上限が「方向の本数」で決まる形になった。音源あたりの残り 8% は、タップの帯域リング描画（1 サンプル × 1 タップの走査）そのものが床で、両耳化の方式では下がらない。次の手はそこの塊処理（別件）。

## 壊れる所
- 上下は畳む（水平の環）。床・天井の反射の上下の手掛かりは出ない（元々弱い）。
- 2 方向の間の音像は 1 本の HRIR より外在化が弱い（櫛形）。物差し上は基準と 0.01 の差。
- 反射の遅れが 2.7 ms 未満のタップは早めきれず、そのぶん遅れて出る（壁から 0.9 m 以内の 1 次だけ）。
- 行の HRIR は 128 タップ（2.7 ms）。低域の ILD の細部は落ちる。
- `TailBusRenderer.enableDirectionBus` を OFF にすれば従来の両耳化に戻る（A/B 用。採用が固まったら旧を消す）。

## 口
- C: `AF_DirectionBusCreate / CreateEx / Destroy / SetHrtf / HasHrtf / Lanes / Render / Rms`、`AF_VoiceSetDirectionBus`。
- ホスト: `TailBusRenderer.enableDirectionBus / directionLanes`（`AcousticFlowSceneDemo.directionBus / directionLanes` から流し込む）。VoiceConvolver は付くまで毎フレーム接続を試す。
