## 0. これは何のテストか

いま手続き生成した幹（340 三角形）が入っているが、**まっすぐすぎてディテールが無い。**
外部 AI で置き換えられるか、工程が回るかを**この 1 件で確かめる。**

比較対象が既にあるので、**良し悪しの判定がしやすい**のがこれを選んだ理由。
うまくいけば崩壊都市のプロップへ横展開する。

## 1. ★いちばん重要な前提 ── 葉は要らない

**生成してほしいのは「葉の落ちた木」＝幹と枝だけ。**

葉はゲーム側が GPU インスタンシングで 12,000 枚を撒いていて、**風で揺れる。**
モデルに葉が付いていると、揺れる葉と揺れない葉が二重になる。

素直に頼むと必ず葉の茂った木が出てくるので、**プロンプトで明示し、出てきたら却下する。**

## 2. 寸法（守れないと嵌まらない）

いまの木の実測。**この寸法に合わせること。**

| | 値 |
|---|---|
| 全高（枝先まで） | **9.4 m** |
| 枝張り | **14 m × 11 m**（横に広い。傘型） |
| 幹の直径（根元 y<1m） | **2.2 m**（根張り込み） |
| 幹の直径（中ほど y=3〜4m） | **1.2 m** |
| 幹が枝に分かれる高さ | **6.5 m** |
| 原点 | **接地面の中心**（根元の中心が (0,0,0)） |
| 単位 | **1 ユニット = 1 メートル** |

### なぜこの寸法か

- **枝は y=6〜8m の高さで、半径 7m まで横に張り出すこと。**
  葉の房がそこに乗る（樹冠の中心 y=7.4m・広がり 15×4.2×15m）。
  枝が上へ伸びる形だと、葉が枝から離れて浮く
- **幹の下から 6.5m は太いまま。**同じ範囲に 1.5 × 6.5 × 1.5m の当たり判定が入る

## 7. 判定 ── この 1 件で何を見るか

| 見るところ | 合格の目安 |
|---|---|
| **寸法が合うか** | 手直しなしで置けるか。ズレるなら工程に補正が要る |
| **葉なしで出せるか** | 出せないなら、AI 3D 生成は「葉のある木」しか作れない＝この用途に向かない |
| **リトポの手間** | 2,000 まで落とすのに何分かかるか。ここが工数の本体 |
| **手続き版より良いか** | 良くなければ、木は手続きのまま磨くほうが早い |

★**「良くならなかった」も立派な結果。**そのときは手続き版の幹に
根張り・枝分かれ・樹皮の溝を足す方向へ戻す（それも 1 時間ほどでできる）。
