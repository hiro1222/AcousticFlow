# 各世界の絵づくり

作成: 2026-08-20 / 世界観・ステージ構成レーン

[WORLD_SETTING.md](WORLD_SETTING.md) が**物語と音響**を持つ。ここが持つのは**絵**だけ ──
色・光・空・霧・シルエット・どこまで作ってどこから描くか。
数値の出どころは [palette.json](palette.json) と `asset_pipeline_spec.md`。

---

## 0. 導き方 ── 音から絵を出す

> **音が世界観を作る**（WORLD_SETTING §0）

これを絵の側でも守る。**各世界の音響の性格は既に確定していて動かせない**ので、
そこから「その音を絵で裏切らないためには何が要るか」を出す。逆にしない。

具体的には、世界ごとにこの順で決める。

1. **音響の性格**（確定・引用するだけ）
2. **そこから出る絵の要請** ← ここが設計
3. 色 / 光・空・霧 / シルエット
4. **到達性の判定** ── 触れるものは作る、見えるだけのものは描く

★4 が工数を決める。`asset_pipeline_spec.md` §0-A の最優先項目で、
曖昧にすると「到達しない遠景を 3D で作って重いだけ」になる（実際に踏んだ）。

## 1. 決定：草原だけが暖色 ── 例外に理由を付ける

> 寒色系で幻想的にしたいのは**後の三世界**。草原は最初だし、いまの穏やかな緑で行く。（発注者・2026-08-20）

`asset_pipeline_spec.md` §0 原則 1 は「スタイル基準は 1 つ。バイオームごとに変えない」。
これを**草原だけ意図的に外す**。好みではなく、**音響の性格が草原だけ違う**から。

| 世界 | 音響 | 壊れているか |
|---|---|---|
| **草原** | 部屋 0・尾なし・遮蔽なし。直接音と HRTF だけ | **無傷** |
| 崩壊都市 | 屋根の残った建物だけが部屋になる | 半分死んでいる |
| 洞窟 | 食い違いの開口で直線が通らない | 方向が嘘をつく |
| 雪山 | 高域から早期反射が消える | 手がかりを奪われる |

**後の三つは全部どこかが壊れているか奪われている。草原だけが揃っている。**
だから草原だけ色が生きていて、扉をくぐるたびに色が抜けていく ──
これは演出ではなく、音響の設計がそのまま絵になったもの。

★ただし**例外は草原 1 つだけ**。後の三世界はマスターパレットから機械的に導いた値を使う。
2 つ目の例外を作った時点で「スタイル基準が 1 つ」は崩れる。

## 2. パレット（マスターからの導出）

`asset_pipeline_spec.md` §0-2 の色相・明度シフトを HSV で機械的に掛けた結果。
**手で選ばない。**新しい色を足さない。

| 役割 | 崩壊都市 | 洞窟 | 雪山 | （草原＝例外） |
|---|---|---|---|---|
| 影・遠景シルエット | `#36434F` | `#262D37` | `#41495F` | `#3B4E57` |
| 中間色 | `#56697A` | `#3C4755` | `#677392` | `#5F7A86` |
| ハイライト面 | `#8195A5` | `#5A6674` | `#9BA8C6` | `#8EABB6` |
| 霧・空気遠近 | `#B6C3CD` | `#7F8790` | `#DAE3F6` | `#C8DBE2` |
| 植生 | `#6E7F63` | `#4B5945` | `#7C9877` | — |

**草原の植生だけ導出値を使わない**（導出は `#7E8C6D`／彩度 22%）。
いまの実装値を維持する:

| | HEX | 彩度 |
|---|---|---|
| 地面 `Grass_Ground` | `#6E9C45` | 56% |
| 草の葉 `Grass_Blade` | `#70992B` | 72% |
| 葉 `Tree_Leaf` | `#4D7533` | 56% |

★草原の**石と空と霧は導出値に寄せる**（`Shrine_Stone #99A3AD` は既にほぼ一致）。
緑だけが例外で、それ以外まで暖色に引っ張らない。

## 3. 世界ごと

### 1 草原 ── 基準

| | |
|---|---|
| **音響（確定）** | 部屋 0・開口 0・尾なし。手がかりは直接音と HRTF だけ。地面 α 0.30 |
| **絵の要請** | **遮るものが無いことが見て分かること。**視界が open で、地平まで抜ける。唯一無傷なので緑が生きている |
| 光・空 | 昼。斜光 38°／−35°。晴天。空は描いた雲（現状は手続き生成の空＝**要差し替え**） |
| 霧 | **低**。28m から 130m。奥行きのためだけ |
| シルエット | **扉ひとつと木ひとつ。それ以外は水平線。**引き算で持たせる |
| 触れる | 円の内側 半径 30m（地面・扉の丘・門・木の幹・川の浅瀬） |
| 描く | 縁の丘（半径 30m の外・**到達不可**）／その外の景色／空 |

⚠ **縁の丘はいま 3D（15,976 三角形）で作ってある。**到達不可なので指示書 §5-B では板ポリの書き割り。
性能問題と同じ根なので、直すときは一緒に。

### 2 崩壊都市 ── 生きている建物と死んだ建物

| | |
|---|---|
| **音響（確定）** | **屋根の残った建物だけが部屋になる**。α 0.15 / RT60 1.5s / 臨界距離 1.26m |
| **絵の要請** | ★**屋根の有無が遠目に読めること。**これが最重要。響く建物＝閉じている＝開口が暗い穴、響かない建物＝上が抜けて空が見える。**音と絵が同じことを言う唯一の世界** |
| 光・空 | 曇り。影は弱く、面の明度差で見せる |
| 霧 | **中**。18m から 80m |
| シルエット | 垂直の柱と水平の梁。折れた鉄骨の斜め線。**割れた床が作る水平の段** |
| 触れる | 建物の躯体・道・瓦礫の山 |
| 描く | 奥のビル群（板ポリ 3〜4 層で視差）／空 |

★ここがプロジェクトの基準点（指示書 §進行順序）。スタイルはここで確立するのが本来の順。

### 3 洞窟 ── 方向が嘘をつく

| | |
|---|---|
| **音響（確定）** | 食い違いの開口で直線が通らない。α 0.038 / RT60 5.1s / 臨界距離 0.83m |
| **絵の要請** | ★**先が見えないこと。**曲がり角で視界が切れる。音が「あっち」と言っても目では確かめられない、という状態を絵が作る |
| 光・空 | **空が無い。**光源は自発光だけ（結晶・天井の裂け目からの光条）。**光源配置がそのままレベルデザイン**（指示書 §5） |
| 霧 | **高**。6m から 34m。閉鎖空間なので近い |
| シルエット | 鍾乳石・石筍の**縦線**。開口の食い違い。層理の水平線 |
| 触れる | 通路・広間の床と壁 |
| 描く | 高い天井／届かない奥の広間 |

⚠ 実機で**最も重い世界**（14.41ms / 56fps）。遮蔽された音源がコストを決めるので、造形を足す前に測る。

### 4 雪山 ── 手がかりの喪失

| | |
|---|---|
| **音響（確定）** | 部屋 0・尾なし。**高域から早期反射が消える**（雪 α 0.30〜0.92）。稜線の回折だけが頼り |
| **絵の要請** | ★**輪郭が溶けること。**白い面に白い雪で、形が読みにくい。**稜線だけが読める** ── 音で頼れるものが稜線の回折だけ、というのと同じ構図 |
| 光・空 | 夜。ただし**真っ暗にしない**（雪の照り返し・WORLD_SETTING §6-4） |
| 霧 | **高**。14m から 70m |
| シルエット | 稜線 3 本。露岩。樹氷の縦線。**白は純白にせず `#DAE3F6` 基調** |
| 触れる | 稜線の内側の雪原・露岩 |
| 描く | 遠景の山脈（板ポリ）／空 |

### 5 海 ── 保留

潮位で部屋グラフが割れ直す（草案 §6）。**時間で世界の形が変わる**唯一の世界。
絵の要請は「水位が見て分かること」になるはずだが、音響の設計が未着手なので**ここでは決めない**。

## 4. 全世界に共通する決めごと

- **輪郭線**（指示書 §6 の必須項目）── **未着手。**いまリムライトだけ。全世界共通で入れる
- **シェーダは 1 枚**（`BellGame/Toon`）。世界ごとに変えるのはマテリアルの設定だけ
- **アニメ調ではディテールよりシルエットが効く**（指示書 §5）。ジオメトリを作り込みすぎると重いだけで見た目は良くならない
- **ベルの在り処が見える飾りを置かない。**音で探すゲームなので、目印がベルの近くにあると音響が飾りになる
- 空（スカイボックス）は 4 世界とも**未着手**。いまは手続き生成の空か Poly Haven の HDRI（写実）で、どちらもアニメ調と合わない
