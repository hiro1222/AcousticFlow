# 直接経路の半影 ── 標本点をやめ、窓の走査線積分に（2026-09-05）

## 何を解くか（不具合 #1 #2）
扉の縁が見通し線を横切るとき、直接経路の生存が 1° で 9〜11 dB 跳んでいた（表ツール 1.5 m、内開き 5→6° −37→−28、8→9° −27→−16。外開き 53→54° −25→−12）。
値が −37／−28／−16／−12 の飛び飛びにしか出ないのが印で、**標本点の階段**だった: 半影は見通し線の中点に置いた窓（帯域ごとのフレネル半径）に標本点を撒き、線分ごとに透過を測っていた。
環 1 つに 4 点しか無いので、扉の細い隙間が「点を含むか含まないか」の二値になる。点を増やしても、隙間が標本の間隔より細い間は二値のまま。
コンセプトの芯（扉が開く瞬間）の跳びなので、不具合の中で最初に直した。

## 形（`computeDirectSoft`、`directPenumbraMode_ == 2`、既定）
開口積分（`portalOpenBands`、戸口の矩形に影を落として行ごとの区間で積む）と**同じ作り**を、直接経路の窓にも使う。
- 窓 = 見通し線の中点に垂直な正方形（半幅 3 m。環の最外と同じ）。
- 影 = 実体の凸包を、リスナー側の物はリスナーから、音源側の物は音源から窓へ落とす（視点の面と窓の面で半空間にクリップ。跨ぐ物は両側から落ちる ＝ 旧の g1×g2 と同じ数え方）。メッシュは三角形ごと。
- 核 = 帯域ごとのガウス exp(−ρ²/r1_b²)（09-02 の環と同じ。開口積分のローレンツ核は裾が重く、3 m の窓では高域まで外側に引きずられた）。**u は区間ごとに解析**（erf）、v は中心に密な等比の行（0.012 → 3 m、片側 28 行）。
- 透過 = 区間の中で影の重なりの τ の積（`computeTransmission` と同じ。実体 1 つに 1 回、エネルギー）。
- 標本の環（mode 1、09-02）と旧の 8 点（mode 0）は `AF_SceneSetDirectPenumbra(1／0)` で残す（聴き比べ用。採用が固まったら消す）。
- ホスト: `AcousticFlowSceneDemo.directPenumbraMode`（Inspector、既定 2。Play 中に動かしてよい。0/1 は聞き比べ用。2026-09-05 追加）。HUD に「直接の半影: 窓の走査線／環の標本点／旧」と出る。

```cpp
// 行ごと: 影の区間の端を並べ、区間の中では τ の積が定数なので核を解析的に積む
// ∫ exp(−(u²+y²)/r²) du = exp(−y²/r²) · (√π r / 2) · [erf(u/r)]
for (int b = 0; b < kNumBands; ++b) numer[b] += hgt * g[b] * I(b, cursor, next);
```

## 数字（探り `AF_ONLY=issues`、1° 刻み、広帯域 dB）
部屋どうしの扉（Test_SwingDoor と同じ形。戸口 1.2 m、手置きのポータル、リスナー z=−4、音源 z=+3.5）:

| 音源 | 生存の 1° 最大段差（前 → 後） | 3 dB 超の回数（前 → 後） | 残った段の正体 |
|---|---|---|---|
| x=−2（蝶番側） | 3.4 → 3.4 dB @18° | 1 → 1 | 開き始め（下記） |
| x=0 | 1.9 → 1.9 dB @18° | 0 → 0 | ― |
| x=+2 | 6.5 → 18.1 dB @9→8° | 2 → 1 | 開き始め（円盤の階段 2 段が 1 段の急な立ち上がりに） |

合成前の担い手を分けると、soft（円盤）の 1° 段差は 19〜26 dB の階段（前）から、開き始めの 1 段だけ（後）になった。開口積分（dif）は前から連続。

外へ開く戸口（表ツールと同じ形。ポータルは経路に入らない）:

| 配置 | soft（円盤）の 3 dB 超（前 → 後） | 生存の 3 dB 超 | 残りの正体 |
|---|---|---|---|
| 内開き 音源 1／2／3 | 階段 → 2／3／2 回（開き始めだけ） | 3／4／3 回 | 稜線回折の経路（dif）が 3〜5° で生まれて消える |
| 外開き 音源 1／2／3 | 階段 → 1／2／2 回 | 10／6／4 回 | 同上（4°・16〜26°・44〜48° に山） |

**開き始めの 1 段は不連続ではない。** 開口率は角度に比例して 0 から立ち上がるので、dB では対数の立ち上がり（0.1° で −28 dB 相当、1° で −18 dB 相当）。閉扉の床（板の透過 −39 dB）からそこへ一気に上がるのは物理どおりで、「扉が開く瞬間に高域から抜けてくる」という前提そのもの。滑らかにする物ではない。

## 分かったこと（次に効く）
- 部屋どうしの扉は、開口積分が連続だったのに**円盤の階段が max で漏れて**いた。走査線にしてそれが消えた。
- 外へ開く戸口の残りは**稜線回折の経路の生まれ消え**（#10 と同じ根、外開きの「2 回折れ」）。半影の物ではない。
- 外へ開く口を直接経路の開口積分に入れる実験（`AF_SceneSetOutsideApertures(2)`）は、開口率が −1 と −34 dB の間で明滅して不安定だった（部屋グラフの除外を付けても同じ）。**入れるなら口の安定化が先**。戻した。
- 部屋グラフの「動く物の除外」は `moved`（動いた印）で見ている。表ツール・探りのように角度ごとに新しく置く扉は除外されず、部屋グラフに扉が入る。ホストでは毎フレーム動くので入らない。

## 退けた書き方
| 案 | なぜ捨てたか |
|---|---|
| 環の点数を増やす | 隙間が標本の間隔より細い間は二値のまま。開き始めを連続にするには数千点が要る |
| 面に張る窓（板の面） | 板が線を掠める角度で窓が張れない（09-02 に却下済み）。窓は見通し線の中点の面に置く |
| 隙間幅の式（`slitWidthGain`） | 3 つ目の式になる。窓の核で 1 つにする |
| 開口積分のローレンツ核 1/(1+ρ²/r1²) を窓にも使う | 裾が重く、3 m の窓では 4 kHz まで外側に引きずられ、ドアなしの正面の音源が −3.9 dB に落ちた（回帰 [主題] ±2 dB が落ちた）。開口積分は矩形で切られるので裾が効かない。窓はガウス（09-02 の環と同じ） |
| 開口積分そのものを直接経路に使う（窓 ＝ 戸口の矩形） | 戸口の無い遮蔽（柱・衝立・外の口）で窓が無い。窓を中点に置けば同じ核で全部を扱える |
| 影を実体ごとの深さの尺度 √(t/(D−t)) で縮める（近い物ほど半影を広く） | 隣り合う扉と枠の影が別々に縮んで継ぎ目に偽の隙間が開く（閉扉 1° で −39 → −21 dB） |
| 尺度を視点ごとに 1 つ（塞ぎの重みで平均した深さ） | 継ぎ目は保てるが、尺度そのものが塞ぎで動いて新しい段を作った（部屋どうしの扉 3.4 → 16.1 dB/°） |

## 壊れる所
- 歩行の走査（回帰 [診断]）: 既定の走りは印 レベル 7 → 6、音源1 の 1 歩最大 2.5 → 1.7 dB。**反射レイなしの走りは 12 → 15 に増え**、戸口の枠の脇（5.34 m）で 7.0 → 9.3 dB（視差の縁。反射が埋めない条件で表に出る）。
- 影は凸包 8 頂点まで（開口積分と同じ）。凹な物は箱の凸包で覆う（塞ぎすぎる側に倒れる）。
- 視点と窓の両方の面を跨ぐ長い物（見通し線に沿う壁）は、2 回のクリップの角が落ちて塞ぎが少し足りない。
- 費用: 影の投影は音源ごと（実体の数 × 2 視点）、行は 56。回帰の 12 本・半分が影で 1 フレーム 8.75〜8.9（環）→ 8.6〜9.9 ms（走査線。走りごとの揺れが大きく、差は 0〜+13% の範囲）。
- **視点の近くの縁は半影が狭く出る**（視差）。中点の窓は r1(D/2) の核なので、深さ t の縁の物理の幅 r1(t)·(D/2)/t より √((D−t)/t) 倍狭い。戸口の枠のすぐ脇（t 0.5 m、D 5.5 m）を歩くと 1 歩 5 cm に 9 dB（環の版は 20 dB）。深さで縮める 2 案は上の表のとおり退けた。直すなら「縁ごとの核」で、別件。
- 開き始めの急な立ち上がりは、扉を 3 秒で 120° 回すと 1 フレームに 1〜2° ＝ 16 dB/フレーム。ホストの平滑（0.35 s）が均す。試聴で確かめる。

## 半影 3 ── 透過の空間の重みを帯域に依らせない（2026-09-08、既定）

### なぜ要ったか
Unity の試聴で「ドアを閉めたときに LPF があまり掛かっていない」。測ると、**戸口に扉がある形（穴のある壁）で閉扉の傾きが材質の半分**しか出ていなかった。

| 場面 | 半影 2 | 半影 3 | 材質 |
|---|---|---|---|
| 一様な仕切り（全部が扉の材質） | 12.1 dB | 12.1 dB | 12.0 dB |
| 戸口に扉（穴のある壁） | **5.6 dB** | **12.2 dB** | 12.0 dB |

（傾き ＝ 20log10(125Hz / 4kHz)。小さいほど「こもっていない」）

原因: 走査線は窓を**帯域ごとのガウス核**で重み付ける。125 Hz の第 1 フレネル帯は半径 2.03 m あり、幅 1 m の扉からはみ出して周りのコンクリート壁を拾う。4 kHz は 0.36 m なので扉に収まる。結果、低域だけ余計に削られて傾きが半分になる。**作品の前提（閉じた扉ごしの音はこもる）が崩れていた。**

### 直し方
**素通しの区間（開口）は帯域ごとの核のまま、塞がっている区間（透過）だけ基準帯の核で重み付ける。**
板は面として再放射するので、どの帯域も同じ面が担う。開口は回折なので帯域ごとで正しい。

```cpp
if (directPenumbraMode_ >= 3 && !active.empty()) {
    const double w = I(kRefBand, cursor, next);          // 塞がっている区間＝透過。基準帯の核
    for (int b = 0; b < kNumBands; ++b) numerTrans[b] += hgt * g[b] * w;
} else {
    for (int b = 0; b < kNumBands; ++b) numer[b] += hgt * g[b] * I(b, cursor, next);
}
...
softE[b] = clamp01(numer[b] / denom[b] + numerTrans[b] / denomRef);
```

### 定数の根拠
| 定数 | 値 | 理由 |
|---|---|---|
| 基準帯 `kRefBand` | 3（1 kHz） | この場面で第 1 フレネル帯の半径 0.72 m。幅 1 m の扉にほぼ収まる。4 kHz（0.36 m）だと見通し線の一点しか見ず「線の透過」に戻る。125 Hz（2.03 m）だと周りの壁を拾う。その中間 |

### 数字
- 戸口の扉の傾き 5.6 → 12.2 dB（材質 12.0）。
- 125 Hz の量は旧の円盤（半影 0）比で −1.8 dB（0.04443 → 0.03600）。半影 2 の −6.8 dB から戻った。
- 一様な仕切りは 12.1 dB のまま（変えていない）。

### 壊れる所
- 閉じた扉の音色が変わる（暗くなる）。**これが狙い。** `directPenumbraMode = 2` で戻せる。
- 透過の空間の重みが帯域に依らないので、「小さい板は低域を通しにくい」という実際の効果は出なくなる。前提を優先した判断。
- 開口（回折）の帯域依存は触っていないので、「狭い隙間は高域から通る」は残る。

### 口
- C: `AF_SceneSetDirectPenumbra(scene, 3)`（既定）。0〜2 は聞き比べ用に残す。
- ホスト: `AcousticFlowSceneDemo.directPenumbraMode`（0〜3、既定 3）。HUD に「直接の半影: 走査線+透過は帯域非依存」。
- 検査: `[閉扉]`（`AF_ONLY=closed`）。一様な仕切りと戸口の扉の両方で材質どおりこもることを見る。

## 開口の法則 ── 出ていった遮蔽物は「蓋」でなくなる（2026-09-08、既定）

★これは直接経路の半影ではなく**開口積分**（`portalOpenBands`）の話。同じ扉の問題なのでここに続けて書く。

### 何を解くか
「扉を開けた瞬間の音色の変化が、開いてからより小さい」（試聴）。測ると、開口は**戸口の面への射影** (1−cosθ) に従っていた（射影との比が 4°/8°/16° で 2.7・2.7・2.3。楔 sinθ ではない）。射影は角度の 2 乗なので、2° で 0.6 mm、4° で 2.4 mm、8° で 9.7 mm。4 kHz の波長 86 mm に対して小さすぎ、**最初の数度に穴が存在しない**。

さらに、開口の音色が**狭いほど暗い**という符号違いもあった（8° で低域が 4.0 dB 大きい）。狭い隙間は波長の長い低域を通さないので、逆でなければならない。

### 形
開いた扉は戸口の面から**出ていく**。閉じているうちは蓋だが、開けば「奥の部屋にある板」になる。これまではその判定が二値だった（完全に奥なら塞がない、少しでも掛かれば完全に塞ぐ）。
**出ていったぶんだけ連続に「蓋」でなくす。** 物差しは**帯域ごとのフレネル半径** r1_b。高域ほど半径が小さいので先に抜ける。

```cpp
// 影を 2 通り作る: 全部の遮蔽物／戸口の面から出ていった物を外したもの
buildRows(false, openRow, begin_, true);
if (hasSwung) buildRows(true, sealRow, beginSeal_, false);
...
const double seal = std::exp(-(swungDepth / r1) * (swungDepth / r1));   // 奥行き 0 で 1
fb = fb + (fs - fb) * (1.0 - seal);        // 出ていったぶん「蓋の無い側」へ寄せる
```

- `depth` ＝ 遮蔽物の中心が戸口の面より奥にある距離。閉じた扉と壁は 0（＝従来と厳密に同じ）。
- 出ていった遮蔽物が無ければ 2 本目は作らない（費用の増分をそこに限る）。
- 到来点は素通しの区間の重心のまま（定位を動かさない）。

### 定数の根拠
| 定数 | 値 | 理由 |
|---|---|---|
| 奥行きの物差し | 帯域ごとの r1 = √(λd₁d₂/(d₁+d₂)) | 遮蔽物が「もう蓋ではない」と言えるのは、フレネル帯の大きさに対して動いたとき。新しい定数を作らずに済み、帯域の順序（高域が先）が自動で出る |
| 形 | ガウス exp(−(d/r1)²) | 走査線の核と同じ。d=0 で 1（従来と一致）、遠ざかると滑らかに 0。折れ目を作らない |

### 数字（回帰 `AF_ONLY=aperture`。幅 1 m の扉・戸口の正面）
| 角度 | 125Hz 前→後 | 4kHz 前→後 |
|---|---|---|
| 2° | 0.0003 → 0.0004 | 0.0003 → **0.0026** |
| 4° | 0.0067 → 0.0070 | 0.0046 → **0.0139** |
| 8° | 0.0261 → 0.0272 | 0.0164 → **0.0528** |
| 16° | 0.0877 → 0.0919 | 0.0529 → **0.1829** |
| 90° | 0.8671 → 0.8749 | 0.8929 → 0.9847 |

4 kHz がほぼ全角度で +10 dB、125 Hz は据え置き。8° の高低比が「低域が 4.0 dB 大きい」→「高域が 2.9 dB 大きい」へ**反転**（7 dB の入れ替わり）。
音色のカーブ（回帰 `AF_ONLY=open`、直接＋回折の和）: 4° 11.5→11.2、8° 8.4→**7.3**、16° 3.2→**2.2** dB。

### まだ届いていない所（記録）
- **0〜2° は動かない。** 回折タップが 3° 未満で 1 本も生まれない（本数 0→1 の二値。不具合 #10 の系統）。かつ 2° の開口は 4 kHz でも 0.26% で、板の透過が作る床（TL 15 dB ＝ 3.2% 相当）に届かない。合成透過損失の式どおり。
- 「開き始めが一番動く」を成立させるには、回折の生まれ方を連続にするか、扉の透過損失を上げて床を下げるかのどちらかが要る。

### 口
- C: `AF_SceneSetApertureLaw(scene, 0|1)`（既定 1）。ホスト: `AcousticFlowSceneDemo.apertureLaw`。HUD に「開口: 出ていった物は蓋でない／面への射影」。
- 検査: `AF_ONLY=aperture`（角度に対する形）、`AF_ONLY=open`（音色のカーブ）。
