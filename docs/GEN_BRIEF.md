# 外部 AI への生成発注

作成: 2026-08-20 / 世界観・ステージ構成レーン

`asset_pipeline_spec.md` の Phase 1 / 3 / 4 / 5-B を**実際に回すための発注書**。
色は [palette.json](palette.json)、絵の方針は [WORLD_VISUAL.md](WORLD_VISUAL.md) から引いている。

**このレーンの担当は Phase 5・6・7（コードと統合）で、生成物は受け取る側。**
受け取ったものがそのまま嵌まるように、要件を先に固定しておく。

---

## 0. 先に読むところ ── 何を頼み、何を頼まないか

指示書 §0 原則 2「AI 3D生成は**置くもの**限定」／原則 3「量産はプロシージャル」。
いま既に**プロシージャルで出ているものは頼まない。**二重に作ることになる。

| | 状態 | 外部 AI に頼むか |
|---|---|---|
| 地形（草原の丘・地面） | 生成器が出している | **頼まない** |
| 草・葉 | GPU インスタンシング | **頼まない** |
| 扉の門・板 | 生成器が出している | **頼まない** |
| 木（幹・枝） | 生成器が出している | **頼まない** |
| 川 | 生成器が出している | **頼まない** |
| **スカイボックス 4 枚** | **無い**（手続き生成の空／写実 HDRI） | ◎ **最優先** |
| **遠景の書き割り** | 無い（草原は 3D で作ってしまっている） | ◎ |
| **プロップ**（瓦礫・廃車・看板・結晶・樹氷） | 無い | ○ 崩壊都市から |
| **ランドマーク**（ドーム遺跡など） | 無い | ○ 崩壊都市から |

★**進行順序**: 指示書は「廃ビル群でスタイル基準を確立 → 縦に 1 本通す」。
`--sref` は**崩壊都市**で取る。草原で取らない。

## 2. Phase 5-B ── スカイボックス（いちばん効く）

**ツール: Midjourney / Nano Banana Pro**

いま 4 世界とも空が無い（手続き生成か写実 HDRI）ので、**画の印象がここで一番変わる。**

### 技術要件（外すと使えない）

| | |
|---|---|
| 形式 | **equirectangular**（正距円筒）。2:1 |
| 解像度 | 8K 目安。生成後にアップスケール工程を挟む |
| 継ぎ目 | **左右端が繋がること。**生成 AI は苦手なので手修正が要る |
| 置き場所 | `UnityDemo/Assets/Textures/Sky/[biome]_8k.*` |
| ★色 | **下の「空の色」と一致させること。**霧と環境光をその値に合わせてあるので、ずれると地平で継ぎ目が見える |

### 世界ごと

| 世界 | 空の色（= 霧の色） | 指示 |
|---|---|---|
| **草原** | `#C8DBE2` | 昼・晴天。**積雲を大きく**。空の面積を広く取る。青は寒色寄りでよい（例外は緑だけ） |
| **崩壊都市** | `#B6C3CD` | 曇り。影が出ない拡散光。低い雲が一様に覆う |
| **洞窟** | ― | **空は要らない。**外が見えない。単色 `#262D37` で潰す |
| **雪山** | `#DAE3F6` | 夜。**真っ暗にしない**（雪の照り返し）。薄い雲と星 |

```
equirectangular 360 panorama sky, seamless horizontal wrap,
[世界ごとの指示], anime background art, painterly clouds,
cool desaturated palette dominated by [空の色 HEX],
flat 2-3 tone shading, no ground, no horizon line objects,
no characters, no text
--ar 2:1
```

## 3. Phase 5-B ── 遠景の書き割り

**プレイヤーが絶対に到達しない遠景は 3D で作らない**（指示書 §5-B）。

★**草原の縁の丘は、いま 3D で 15,976 三角形ある。**到達不可（30m で押し戻される）なので、
本来は板ポリ 1 枚。**性能問題と同じ根**なので、書き割りが届いたら差し替える。

| 世界 | 要るもの | 層 |
|---|---|---|
| 草原 | 丘の向こうの野と遠い山並み | 2〜3 層 |
| 崩壊都市 | 奥のビル群 | 3〜4 層（視差が効く） |
| 雪山 | 遠景の山脈 | 2〜3 層 |

```
Distant background layer for a game, [対象],
seen from far away, no foreground detail,
transparent background above the horizon,
anime background art, cool desaturated palette
(#36434F #56697A #8195A5), flat shading,
strong silhouette, no characters, no text
--ar 21:9
```

要件: **透過 PNG**（空を抜く）／横に長く／`UnityDemo/Assets/Textures/Backdrop/` へ。
視差が欲しければ距離別に 3〜4 層。

## 4. Phase 3〜4 ── プロップとランドマーク

**崩壊都市のブロックアウト寸法が来てから。**それまで着手しない（指示書「4 つ同時に進めない」）。

生成の要件（指示書 §Phase 3 の雛形に色を差し込んだもの）:

```
Single isolated object: [対象], plain white background,
orthographic-ish view, [front / side / 45deg / back],
anime-style rendering, cool desaturated palette
(#36434F #56697A #8195A5), clean linework,
no ground shadow, no scenery, no characters
```

### 受け取り側（私）の必須要件

これを外すとシーンに嵌まらない。

| | |
|---|---|
| **1 ユニット = 1m** | 指示書 §0-3。スケール検証は必ず通す |
| **原点** | 接地面の中心。扉の板だけは例外で**板の中心**（物理で回るため） |
| **コライダー** | **付けないで渡す。**こちらで判断して付ける。付けた物だけが音を遮る |
| ポリゴン数 | 下の規定に従う |
| 形式 | `.glb` |

### ★ポリゴン数の規定（指示書 §0-3・2026-08-20 決定）

いまの実装の実測から逆算した。**プレイヤーが注視する時間**でだいたい分かれる。

| 段 | 上限（三角形） | 何が入るか | いまの実例 |
|---|---|---|---|
| **ランドマーク** | **8,000** | 唯一無二・注視する | 扉の門 3,134 |
| **中景** | **2,000** | 複数配置・近づける | 鐘 1,700／扉の板 592／木 340 |
| **小物** | **500** | 数を撒く・遠くから見る | 火鉢 452／扉の枠 40 |

★**分類 C（構造・地形）はこの 3 段に入らない。**1 個の物ではないため。
代わりに **1 世界あたりの合計 60,000** を目安にする（超えたら疑う、という程度の線）。

#### いまの棚卸し

| | 三角形 | 判定 |
|---|---|---|
| `Stage1_Grassland`（株・穂・花） | **56,078** | ⚠ **株 1,853 個で 44,500**。インスタンシングへ移せば 1 万を切る |
| `Stage1_Hills` | **15,976** | ⚠ **到達不可なのに 3D**。書き割りへ（§3） |
| `Stage3_Cave` | 14,376 | 洞窟の壁。到達可能なので妥当だが、意匠を足す前に測る |
| `Stage2_Temple` | 8,096 | **捨て**（神殿は廃止） |
| `Stage4_Snow` | 6,272 | 妥当 |
| `Prop_Shrine_Grassland` | 3,134 | ランドマーク 8,000 内 |
| `Stage1_Mound` / `Stage1_River` | 2,738 / 1,440 | 構造。妥当 |
| `Prop_Bell` | 1,700 | 中景 2,000 内。**ただし一番注視される**ので、上げるならここ |
| その他のプロップ | 40〜592 | 規定内 |

**草原の構造合計**: 56,078 + 15,976 + 2,738 + 1,440 = **76,232**。目安 60,000 を超えている。
上の 2 つ（⚠）を直せば **約 2 万**まで落ちる。

## 6. 優先順

1. **`--sref` を崩壊都市で取る**（Phase 1）── 全部の基準
2. **スカイボックス 4 枚**（Phase 5-B）── 画の印象がいちばん変わる。洞窟は単色で足りる
3. **遠景の書き割り**（Phase 5-B）── 草原の縁の丘を差し替えて性能も戻す
4. 崩壊都市のプロップ・ランドマーク（Phase 3〜4）── ブロックアウト寸法待ち

**私の側で先に要る決定**: ポリゴン数の 3 段階規定（指示書 §0-3）。
これが無いと、受け取ったモデルを「重すぎる」と判断する根拠が無い。
