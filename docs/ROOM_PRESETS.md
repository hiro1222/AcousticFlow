# 部屋の響きのプリセット ── 材質として持つ（2026-09-08）

## 何を解くか
「今みたいな後反響」と「木造の部屋」のように、部屋の響きを名前で選んで聞き比べたい。

## 形（プリセット＝材質。RT60 の表は別に持たない）
部屋の残響は `room_graph.h` の Sabine（RT60 = 0.161 V / (ΣSα + 4mV)）が**形と材質から**出す。反射も尾もエコグラムも同じ材質を引く。
だから「響きのプリセット」を RT60 の表として別に持つと、反射・尾・RT60 の答えが 2 つになる（決めごと #1）。
プリセットは `material.cpp` の材質として足し（唯一の出どころ）、ホストは `AF_MaterialPresetBands` で引く。

| id | 名前 | 何 | α（125 → 4k） | TL[dB]（125 → 4k） | 散乱 |
|---|---|---|---|---|---|
| 1 | Concrete | 今の後反響（打ちっぱなし） | 0.02 → 0.07 | 34 → 60 | 0.05 → 0.35 |
| 5 | WoodRoom | 板張りの部屋（壁・床・天井の面積平均） | 0.25 → 0.10（低域が最大） | 22 → 39 | 0.08 → 0.40 |
| 6 | Stone | 石積み（遺跡・神殿） | 0.03 → 0.08 | 36 → 62 | 0.20 → 0.80（粗い） |
| 7 | Cave | 岩肌（洞窟） | 0.04 → 0.12 | 60 → 80 | 0.35 → 0.95（ごく粗い） |
| 8 | Snow | 新雪 | 0.35 → 0.95 | 20 → 37 | 0.30 → 0.90 |
| 0 | Default | 内壁（両面張りの間仕切り） | 0.10 → 0.40 | 31 → 52 | 0.10 → 0.50 |

- α は Egan / Kuttruff の表の値（合板の壁 0.28/0.22/0.17/0.09/0.10/0.11、木の床 0.15/0.11/0.10/0.07/0.06/0.07 など）を、壁 43%・床 29%・天井 29%（8×8×3 m）で面積平均した。TL は質量則沿いの目安、散乱は面の粗さ。値は暫定で、実測で差し替える前提は他の材質と同じ。
- ★「木造＝温かい」は板ではなく畳・布・障子の吸音から来る。板張りだけだと**低域が吸われて乾いた響き**になる（125 Hz の RT60 が 1 kHz の 1/3）。温かくしたいときは床に `AcousticSurface` の Adjusted（吸音 2〜3 倍）を当てる。

## 直した所（一緒に見つかった二重）
`setMaterial` / `setInstanceMaterial` で材質を差し替えても、部屋グラフは登録時に写した吸音のままだった（反射・尾は新しい材質、RT60 は古い材質）。差し替えた実体の領域を部屋グラフに触らせて作り直すようにした（動く物は部屋グラフに入っていないので触らない）。

## 数字（回帰 `[材質]`、`AF_ONLY=materials`。閉じた箱 8×8×3 m、V 165 m3）
| 材質 | RT60 125 | 250 | 500 | 1k | 2k | 4k |
|---|---|---|---|---|---|---|
| Concrete | 6.44 | 6.38 | 4.23 | 3.15 | 2.44 | 1.63 |
| Stone | 4.30 | 4.27 | 3.19 | 2.53 | 2.05 | 1.45 |
| Cave | 3.23 | 2.57 | 2.14 | 1.60 | 1.26 | 1.00 |
| WoodRoom | 0.52 | 0.68 | 0.86 | 1.42 | 1.39 | 1.19 |
| Default | 1.29 | 1.29 | 0.86 | 0.64 | 0.43 | 0.32 |
| Snow | 0.37 | 0.22 | 0.16 | 0.14 | 0.14 | 0.13 |

- 差し替えの追従: Concrete 4.23 s → `setMaterial` で WoodRoom 0.86 s（箱を登録し直さずに一致）→ 壁 1 枚を `setInstanceMaterial` で Snow 0.59 s。
- WoodRoom と Default は 500 Hz で同じ 0.86 s だが形が逆（板は低域を吸い、内壁は高域を吸う）。聞き分けはそこ。

## 壊れる所
- `AcousticFlowSceneDemo.occluderMaterial` を Play 中に変えると（L キーでも）既定の材質が**書き換わる**ので、`AcousticSurface` の無い occluder が一斉に変わる。`AcousticSurface` を付けた面（扉など）はそのまま。
- 材質の差し替えのたびに部屋グラフの当該領域が作り直される（一度だけ数 ms〜数十 ms）。毎フレーム差し替える使い方は想定していない。
- 既存 0〜4 の値は変えていない。回帰の既存の節に影響なし。

## 口
- C: `AF_MaterialPresetBands(5..8)`。`AF_SceneSetMaterial` / `AF_SceneSetInstanceMaterial` は部屋の Sabine も追いつく。
- ホスト: `AcousticMaterialPreset.WoodRoom / Stone / Cave / Snow`、`AcousticFlowSceneDemo.occluderMaterial`（Inspector、Play 中可）、**L キー**で Concrete → WoodRoom → Stone → Cave → Snow → Default を巡る。HUD に「部屋の材質(L): … Sabine RT60 125/500/4k」。
