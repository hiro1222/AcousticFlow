# 早期反射（B: 拡散リグ方式）

各音源の初期反射「エネルギー」だけを取り出し（**方向は捨てる**）、リスナー基準で**左右対称に配置した
拡散リグ**（前後左右4方向）から、音源と同じ音を同レベルで鳴らす。壁の点を指さない＆左右対称なので
**直接音の定位を引っ張らず**、別ボイス＝無相関で「広がり・包まれ感」だけ足す。

> **なぜ像源ピン留めをやめたか（2026-07-09）:** 当初は像源位置に3Dボイスを立てる方式だったが、
> 反射が壁の点に**露骨に定位して直接音の像がにじむ**（F off で直接がシャープに戻ると実証）。
> 現実でも初期反射は**先行音効果で定位せず「幅」に化ける**ので、無指向の拡散リグが物理的にも正しい。
> 定位は「第一波面」＝直接音（見通せる）／遮蔽時は回折の回り込み角、だけが担う。

## なぜ Wwise Reflect をやめたか

当初は AkReflect（Wwise Reflect）へ像源を送る実装だったが、**Wwise Reflect は有料ライセンス必須**の
プラグインで、ライセンス無しの環境ではバンク生成時に除外（`No license for 'Wwise Reflect' ... [Missing]`）
され無音になる。配布 exe にトライアル制限（定期ノイズ/時限）を載せたくないので、
**ライセンス不要でクリーンに配布できる仮想エミッタ方式**へ切り替えた。

副次的に、これは移植理念にむしろ忠実：**エンジンは可搬なタップ（像源位置＋帯域ゲイン）を計算し、
ホストは手持ちの手段で描画する**。ここでは Wwise の 3D ボイス、将来の DirectX ホストなら別の描き方、
最終的にはフルIR畳み込み——同じタップを使い回せる。

## データフロー

```
Core: computeEarlyReflections(listener, source)
   → 6帯域ゲイン[] (0..1)   ※像源位置も返るが方向は使わない
        ↓ C# demo (UpdateEarlyReflections)
   タップの低域加重ゲインを合算＝この音源の反射エネルギー（スカラ）
        ↓
   リスナー基準の左右対称な拡散リグ（FL/FR/BL/BR 4方向）へ同レベルで流す
   （壁を指さない・対称なので直接音の定位を引っ張らない／別ボイス＝無相関で広がり）
        ↓
   Wwise の 3D 定位（HRTF/パンニング）が空間化
```

## 実装の要点

- **方向は捨てエネルギーだけ**使う: タップの向き（どの壁か）は使わない。これが「反射を定位させない」肝。
- **左右対称リグ**: 音源 s × リグ方向 k（`ReflectRigSize=4`：FL/FR/BL/BR）で一意な GameObject ID
  （`ReflectId(s,k)`）。リスナー基準・水平・頭の向きで回る。対称なので像を引っ張らない。
- **同期投入**: リグ・エミッタは初期化時に直接音と**同フレームでまとめて** `PostEvent`
  （`SetupReflectionEmitters`）。後からバラバラだと拍がズレる。
- **毎フレーム**: リグの**位置（listener + rigDir×radius）と出力音量**だけ更新。音量 = 反射エネルギー
  × `earlyReflectLevelScale` ÷ √リグ数（無相関ボイスの合成パワーを揃える）。再生し直さない。
- **F キー**: ON/OFF。OFF は全ミュート（ボイスは残す）。初回 ON は遅延生成。

総リグ・ボイス数 = 音源数 × `ReflectRigSize`（既定 6×4=24）＋ 直接 6 = 30 ボイス。

## デモ側パラメータ（Inspector「早期反射 (B: 拡散リグ)」）

| 項目 | 意味 |
|---|---|
| `enableEarlyReflections` | ON/OFF（F キーと同じ） |
| `earlyReflectTaps` | エネルギー算出に使うタップ数（方向は未使用）。4〜8 |
| `earlyReflectRadius` | 拡散リグの半径(m)。リスナーからこの距離に前後左右のリグを置く |
| `earlyReflectRays` / `earlyReflectBounces` | 抽出レイ本数 / 反射回数（初期反射は 1〜2） |
| `earlyReflectUpdateEveryFrames` | 更新間隔（音源ごとにレイを撒くので数frame毎） |
| `earlyReflectLevelScale` | 反射音の全体レベル倍率（小さいと控えめ） |

## Wwise 側

**追加オーサリング不要**。音源イベント（`Vocal/Guitar/…`）がそのままリグ・ボイスにも使われる。
（試作で作った `Reflections` aux バス＋AkReflect は未使用。残しても無害だが消してよい。）

## 今後の改良余地

- **横成分の強調**: L/R（幅）を前後より少し強めると ASW（音像の幅）が出やすい。
- **6帯域 EQ**: リグ・ボイスに音源ごと RTPC で帯域別 Gain → 壁材質の色付けを反映。
- 定位を担うのは直接＋回折だけ。反射・残響は無指向（[[early-reflections-virtual-emitter]] 参照）。
- 最終形は**フルIR畳み込み**（直接＋回折＋反射＋残響尾を1つの応答にまとめて畳み込む）。
