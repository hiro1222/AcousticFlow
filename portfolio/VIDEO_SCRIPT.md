# 紹介動画 90 秒 ── テロップ台本

**ナレーションなし。音は全部ゲーム音。**文字だけで進めます。

---

## テロップの決めごと

| | |
|---|---|
| 書体 | 太めのゴシック（Yu Gothic UI Bold / Noto Sans JP Bold） |
| 大きさ | 主文 48〜56px ／ 補足 28〜32px（1920×1080 基準） |
| 色 | 白 `#FFFFFF` ／ 強調は **ティール `#16C1C1`** ／ 数字は **インディゴ `#5B5BD6`** |
| 下敷き | 濃紺 `#151A24` を 80% 不透明で。**文字だけを画面に置かない**（画が明るいと消える） |
| 位置 | 主文＝**下から 1/4**。補足＝主文の直下。ラベル＝左上 |
| 出入り | 0.2 秒でフェード。**動かさない**（スライドやポップは画を邪魔する） |
| 分量 | **1 行 20 字まで。2 行まで。**読めない文字は無いのと同じ |
| 数字 | **1 カットに 1 つまで** |

⚠ **画面隅の 2D 俯瞰図は Unity 側で描いて録る。**編集で足すと音とずれます。
